**NTi IT-Tender Bot** พัฒนาขึ้นมาเพื่อช่วยทีมงานฝ่ายขายโครงการ (Project Sales), ทีมวิศวกรออกแบบระบบ (System Engineers), และผู้บริหารของ **บริษัท นิวเทคโนโลยี่อินฟอร์เมชั่น จำกัด** ในการค้นหา ติดตาม และวิเคราะห์โครงการประมูลจัดซื้อจัดจ้างภาครัฐ (e-GP กรมบัญชีกลาง), รัฐวิสาหกิจ และภาคเอกชน โดยเน้นสายงานที่บริษัทมีความเชี่ยวชาญเป็นพิเศษ

## 🎯 6 หมวดหมู่งานหลักของ NTi ที่ระบบตรวจจับและคัดกรอง

1. 💻 **จัดซื้อคอมพิวเตอร์และอุปกรณ์ต่อพ่วง (PC & Hardware Procurement)**
   - คอมพิวเตอร์สำนักงาน (PC Desktop / All-in-One), โน้ตบุ๊ก (Notebook/Laptop)
   - คอมพิวเตอร์ประมวลผลประสิทธิภาพสูง (Workstation), เครื่องแม่ข่าย (Server Rack / Blade), Storage SAN/NAS
   - เครื่องพิมพ์ เครื่องสแกนเนอร์ และอุปกรณ์ต่อพ่วง
2. 🛠️ **งานบริการบำรุงรักษาและซ่อมแซม (MA & PM Services)**
   - สัญญาบริการบำรุงรักษาเชิงป้องกัน (Preventive Maintenance - PM) รายเดือน/รายไตรมาส/รายปี
   - สัญญาบริการซ่อมบำรุงเครื่องคอมพิวเตอร์และอุปกรณ์ระบบสารสนเทศ (Maintenance Agreement - MA)
   - งานจ้างบริการสนับสนุนไอที Helpdesk & Onsite Support ประจำสำนักงาน
3. 🔌 **งานเดินระบบสายสัญญาณและไฟฟ้า (Cabling & Electrical Systems)**
   - เดินสายสัญญาณคอมพิวเตอร์ Structured Cabling (UTP Cat5e / Cat6 / Cat6A)
   - เดินสายใยแก้วนำแสง (Fiber Optic Single-Mode / Multi-Mode) และงาน Fusion Splicing / OTDR Test
   - งานจัดระเบียบตู้ Rack, ตู้เซิร์ฟเวอร์, ราง Wireway / ท่อร้อยสาย EMT
   - งานระบบจ่ายไฟฟ้าและเครื่องสำรองไฟฟ้าอัตโนมัติ (UPS) ห้อง Data Center / Server Room
4. 🌐 **งานระบบเครือข่ายและความปลอดภัย (Network & Cybersecurity)**
   - Core Switch, Distribution Switch, PoE+ Access Switch (Cisco, Aruba, Huawei ฯลฯ)
   - ระบบเครือข่ายไร้สาย Wi-Fi 6 / 6E พร้อม Controller และระบบพิสูจน์ตัวตน (Captive Portal)
   - อุปกรณ์รักษาความปลอดภัย Next-Generation Firewall (Fortinet, Palo Alto)
   - ระบบจัดเก็บข้อมูลการจราจรทางคอมพิวเตอร์ (Log Server) ตาม พ.ร.บ.คอมพิวเตอร์ฯ
5. 📹 **งานระบบห้องประชุมอัจฉริยะและระบบภาพและเสียง (Meeting Room & AV)**
   - ระบบการประชุมทางไกลผ่านจอภาพ (Video Conference: Zoom Rooms, Microsoft Teams Rooms, Cisco Webex)
   - จอภาพสัมผัสอัจฉริยะ (Interactive Display / Smart Board) และจอ LED Full Color Wall
   - ระบบไมโครโฟนชุดประชุมดิจิทัล ลำโพง และชุดประมวลผลสัญญาณเสียง (DSP)
   - ระบบควบคุมอุปกรณ์ภาพและเสียงส่วนกลาง (Central AV Control System)
6. 📦 **ซอฟต์แวร์ ลิขสิทธิ์ และพัฒนาระบบ (Software & Application)**
   - ลิขสิทธิ์ระบบปฏิบัติการ Windows และโปรแกรมสำนักงาน Microsoft 365, Antivirus
   - พัฒนาเว็บแอปพลิเคชัน (Web Portal) และโมบายล์แอปพลิเคชัน (Mobile App) บริการประชาชน

## 🚀 วิธีการใช้งาน (Quick Start Guide)

### วิธีที่ 1: เปิด Interactive Web Dashboard (แนะนำ สะดวกที่สุด)
1. ดับเบิลคลิกไฟล์ **`start_dashboard.bat`** (หรือดับเบิลคลิกที่ **`index.html`**)
2. หน้าจอ Dashboard จะเปิดขึ้นมาบนเว็บเบราว์เซอร์ของคุณทันที:
   - **ค้นหาแบบ Real-Time**: พิมพ์คำค้นหา เช่น `คอมพิวเตอร์`, `MA`, `LAN`, `ห้องประชุม`, `นนทบุรี`
   - **คลิกหมวดหมู่งานของ NTi**: เช่น กดปุ่ม `🛠️ งานจ้าง MA & PM` หรือ `📹 ห้องประชุม`
   - **กรองตามงบประมาณ**: เช่น เลือกรุ่นเฉพาะเจาะจง (< 5 แสนบาท) หรือ e-Bidding (2-5 ล้านบาท)
   - **ดูรายละเอียดและ TOR**: คลิกที่การ์ดโครงการใดก็ได้เพื่อดูสเปกสรุป และกดปุ่ม `e-GP` เพื่อเปิดหน้าเว็บกรมบัญชีกลาง
   - **ระบบ Pipeline (Watchlist)**: กดไอคอน ⭐ ที่โครงการเพื่อบันทึกและจัดการขั้นตอนทำราคา
   - **ส่งออก Excel**: กดปุ่ม `ส่งออก Excel/CSV` ด้านบนขวาเพื่อนำข้อมูลไปวิเคราะห์ต่อ

### วิธีที่ 2: รันบอทเฝ้าระวังงานใหม่อัตโนมัติ (Auto-Watcher 24/7)
1. ดับเบิลคลิกไฟล์ **`start_auto_watcher.bat`** (หรือคลิกขวาที่ `auto_tender_watcher.ps1` แล้วเลือก *Run with PowerShell*)
2. บอทจะวนลูปสแกนข้อมูลจาก `data.go.th` และ e-GP อัตโนมัติ (ทุกๆ 5 นาที หรือตั้งค่าได้)
3. เมื่อตรวจพบโครงการใหม่ที่ตรงกับสายงาน NTi (>90%):
   - มีเสียงแจ้งเตือน (Beep Alert)
   - อัปเดตไฟล์ `tenders_latest.csv` และ `tenders_latest.json` แบบสดๆ ทันที

### วิธีที่ 3: รันบอทสแกนครั้งเดียว (One-Time Scan)
- ดับเบิลคลิกไฟล์ **`run_bot.bat`** (รัน `nti_tender_bot.ps1`) เพื่อสแกนและส่งออกไฟล์สรุปทันที

### วิธีที่ 4: รันบอทผ่าน Python (สำหรับผู้ใช้งาน Python)
```bash
python nti_tender_bot.py
```

## 🔮 ทำไมหน้าเว็บ e-GP ถึงมีข้อมูลถึงปีงบประมาณ 2570?

ตาม **พ.ร.บ. การจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560** มาตรา 11 กำหนดให้หน่วยงานของรัฐทุกแห่งจัดทำ **"แผนการจัดซื้อจัดจ้างประจำปี (Annual Procurement Plan)"** และประกาศเผยแพร่ในระบบเครือข่ายสารสนเทศของกรมบัญชีกลาง (`www.gprocurement.go.th`) และของหน่วยงานของรัฐก่อนเริ่มกระบวนการจัดซื้อจัดจ้างจริง

ดังนั้นในระบบ e-GP จะปรากฏ:
1. **ปีงบประมาณ 2570 (แผนจัดซื้อจัดจ้างล่วงหน้า)**: รายการงบประมาณจัดซื้อ PC ล็อตใหญ่, สัญญาจ้าง MA/PM ระบบคอมพิวเตอร์รายปี, งานวางระบบเคเบิล Fiber Optic, และโครงการห้องประชุมอัจฉริยะล่วงหน้า ซึ่งเป็นโอกาสทองของ NTi ในการติดต่อหน่วยงาน จัดทำสเปก และจับมือพันธมิตรสินค้าไอทีก่อนคู่แข่ง
2. **ปีงบประมาณ 2569 (ประกาศเชิญชวน & e-Bidding)**: โครงการที่กำลังเปิดรับซอง ยื่นข้อเสนอ และร่าง TOR ในปัจจุบัน
3. **ปีงบประมาณ 2568 (โครงการต่อเนื่อง & อ้างอิงราคากลาง)**: โครงการฐานข้อมูลย้อนหลัง

ระบบ NTi IT-Tender Bot ได้รวบรวมทั้ง **แผนจัดซื้อจัดจ้างล่วงหน้า ปี 2570** และ **งานเปิดรับซองจริง ปี 2569** ไว้อย่างครบถ้วน 40 โครงการ พร้อมตัวกรองแยกปีงบประมาณได้ชัดเจน 100%
